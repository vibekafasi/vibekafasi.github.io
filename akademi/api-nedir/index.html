Akademi / Modül 2: Temel kavramlar

API nedir? API anahtarı ne işe yarar?

API, programların birbirinden hizmet istediği kapıdır. Garson benzetmesiyle API'yi, API anahtarını ve anahtarı güvende tutmanın kurallarını öğren.

Ders 5/67 dk okumaGüncel: Kasım 2026

Kargo takip numarasını bir siteye yazınca paketinin nerede olduğunu görürsün. O site kargo firmasının bilgisayarına girmez; ondan kibarca bilgi ister. Bu isteğin yapıldığı kapıya API denir. Kendi uygulamanda yapay zekâ kullanmak, döviz kuru göstermek ya da bir pazar yerindeki siparişlerini çekmek istediğinde de hep bu kapıyı kullanacaksın.

Garson benzetmesi

Restoranda mutfağa girip yemeği kendin pişirmezsin. Garsona menüden bir şey söylersin, garson siparişi mutfağa götürür, tabağı sana getirir. API garsondur. Menü, API'nin dokümantasyonudur: neler istenebileceğini ve nasıl isteneceğini yazar. Sipariş senin isteğindir, tabak da gelen yanıttır. Mutfağın içinde ne olduğunu bilmen gerekmez; menüdeki kurallara uyman yeter.

API ile neler yapılır?

  • Uygulamana yapay zekâ eklemek: senin sitenin Claude ya da GPT modellerine soru gönderip cevap alması.
  • Hava durumu, döviz kuru, harita gibi hazır bilgileri kendi sayfanda göstermek.
  • Satış yaptığın pazar yerinden sipariş ve stok bilgilerini çekmek; çoğu büyük pazar yerinin satıcılar için bir API'si vardır.
  • Telegram'a otomatik mesaj göndermek, e-posta atmak, ödeme almak.

API'ler genelde cevabı JSON denen düzenli bir metin biçiminde verir. Aşağıda bir isteğin ve yanıtın sade bir örneğini görüyorsun:

API anahtarı: hem kimlik kartın hem kredi kartın

Birçok API, kimin istek yaptığını bilmek ister. Bunun için sana uzun, karmaşık bir şifre verir: API anahtarı. Uygulaman her istekte bu anahtarı gösterir. Hizmet de kullanımı ve faturayı o anahtarın sahibine, yani sana yazar.

Otel kartı benzetmesi

API anahtarı, otelde odanın kapısını açan ve aynı zamanda restoran harcamalarını odana yazdıran karta benzer. Kartı kaybedersen bulan kişi hem odana girer hem de senin hesabına yemek yer. Bu yüzden API anahtarı bir şifre kadar, hatta ondan daha dikkatli saklanmalıdır.

Örneğin Claude API'sinin anahtarı Claude Console'daki API anahtarları sayfasında oluşturulur. OpenAI'ın anahtarları ise OpenAI'ın geliştirici platformunda oluşturulur. Dikkat: claude.ai ya da ChatGPT aboneliği ile API kullanımı ayrı ürünlerdir; API kullanımı genelde ayrıca ve kullandıkça ücretlendirilir. Güncel ücretleri her zaman resmî fiyat sayfasından kontrol et.

API anahtarının 5 altın kuralı

  • Sohbete yapıştırma. Yapay zekâya kod yazdırırken anahtarın kendisini değil, “anahtar .env dosyasında duruyor” bilgisini ver.
  • Ön yüze koyma. Tarayıcıda çalışan koda yazılan anahtarı herkes görebilir.
  • GitHub'a yükleme. .env dosyası .gitignore listesinde olmalı. Bunu güvenlik modülünde (Modül 6) adım adım yapacağız.
  • Harcama sınırı koy. Panelde kullanımını izle ve izin veriyorsa bir harcama sınırı belirle.
  • Sızdıysa hemen iptal et. Anahtarın görüldüğünden şüphelenirsen paneldeki anahtarı sil ve yenisini oluştur.
Dikkat

Herkese açık bir GitHub deposuna yüklenen anahtarlar, otomatik tarayıcı programlar tarafından dakikalar içinde bulunabilir. Anthropic, GitHub'ın gizli bilgi tarama programına katılır ve herkese açık depolarda bulunan Claude API anahtarlarını otomatik olarak devre dışı bırakır. Ama buna güvenme; anahtarı hiç yüklememek tek gerçek çözümdür.

Anahtarsız bir API'yi tarayıcında dene

  1. Tarayıcının adres çubuğuna https://api.github.com/users/octocat yaz ve Enter'a bas. Octocat, GitHub'ın maskotunun hesabıdır.
  2. Ekrana süslü parantezlerle dolu bir metin gelecek; Firefox bunu düzenli bir görünümle de gösterebilir. Bu, GitHub API'sinin JSON biçimindeki yanıtıdır.
  3. İçinde "login", "name", "public_repos" gibi etiketleri bul. Her etiketin yanında bir değer var.
  4. Adresin sonundaki octocat yerine başka bir GitHub kullanıcı adı yazıp tekrar dene. Garsona farklı bir sipariş vermiş oldun.

Akılda kalsın

  • API, programların birbirinden hizmet istediği garsondur; menüsü dokümantasyondur.
  • API anahtarı hem kimliğin hem faturandır; şifre gibi, hatta daha dikkatli sakla.
  • Anahtarı sohbete, ön yüze ve GitHub'a koyma; sızarsa hemen iptal et.

Kendini dene

3 kısa soru. Cevabı seç, doğrusunu hemen gör.

1Garson benzetmesinde API'nin dokümantasyonu neye karşılık gelir?

Dokümantasyon, menü gibi neler istenebileceğini ve nasıl isteneceğini anlatır.

2Yapay zekâ sana “API anahtarını buraya yapıştır, kodu ben yazayım” dedi. En doğru davranış hangisi?

Anahtar hiçbir zaman sohbete, ön yüze ya da herkese açık depoya konmaz; .env gibi gizli bir dosyada durur.

3API anahtarının sızdığından şüpheleniyorsun. İlk ne yapmalısın?

Sızan anahtar başkalarının elinde olabilir. Silinip yenisinin oluşturulması gerekir; sadece paylaşılan yerden silmek yetmez.
