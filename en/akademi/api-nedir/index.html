What is an API? What is an API key for?

An API is the door programs use to request services from each other. Learn APIs, API keys and the rules for keeping keys safe with a waiter analogy.

Lesson 5/67 min readUpdated: November 2026

When you type a tracking number into a site, you see where your package is. That site doesn't break into the shipping company's computer; it politely asks it for the information. The door this request goes through is called an API. Whenever you want to use AI in your own app, show exchange rates or pull your orders from a marketplace, you'll use this kind of door.

The waiter analogy

At a restaurant you don't walk into the kitchen and cook the food yourself. You tell the waiter something from the menu, the waiter takes the order to the kitchen and brings you the plate. The API is the waiter. The menu is the API's documentation: it says what you can ask for and how to ask. The order is your request, and the plate is the response that comes back. You don't need to know what goes on inside the kitchen; you just follow the rules on the menu.

What can you do with an API?

  • Add AI to your app: your site sends questions to Claude or GPT models and gets answers back.
  • Show ready-made information like weather, exchange rates or maps on your own page.
  • Pull order and stock information from the marketplace you sell on; most big marketplaces have an API for sellers.
  • Send automatic messages to Telegram, send emails, take payments.

API key: your ID card and your credit card in one

Many APIs want to know who is making the request. For that, they give you a long, complicated password: an API key. Your app shows this key with every request. The service then charges usage and billing to the key's owner, which is you.

The hotel key card analogy

An API key is like a hotel card that opens your room door and also charges restaurant bills to your room. If you lose the card, whoever finds it can get into your room and eat on your tab. That's why an API key must be kept as carefully as a password, or even more carefully.

For example, a key for the Claude API is created on the API keys page of the Claude Console. OpenAI's keys are created on OpenAI's developer platform. Note: a claude.ai or ChatGPT subscription and API usage are separate products; API usage is usually billed separately, based on how much you use. Always check current prices on the official pricing page.

5 golden rules for API keys

  • Don't paste it into a chat. When having AI write code, don't give it the key itself; tell it “the key is in the .env file.”
  • Don't put it in the frontend. Anyone can see a key written into code that runs in the browser.
  • Don't upload it to GitHub. The .env file must be on the .gitignore list. We'll do this step by step in the security module (Module 6).
  • Set a spending limit. Watch your usage in the dashboard and, if it allows, set a spending limit.
  • If it leaked, revoke it right away. If you suspect someone saw your key, delete it in the dashboard and create a new one.
Watch out

Keys uploaded to a public GitHub repository can be found by automated scanning programs within minutes. Anthropic takes part in GitHub's secret scanning program and automatically disables Claude API keys found in public repositories. But don't rely on that; never uploading the key is the only real solution.

Try an API that needs no key, in your browser

  1. Type https://api.github.com/users/octocat into your browser's address bar and press Enter. Octocat is the account of GitHub's mascot.
  2. Text full of curly braces will appear; Firefox may also show it in a tidy view. This is the GitHub API's response in JSON format.
  3. Find labels inside it like "login", "name" and "public_repos". Each label has a value next to it.
  4. Replace octocat at the end of the address with another GitHub username and try again. You just gave the waiter a different order.

Key takeaways

  • An API is the waiter programs use to request services from each other; its menu is the documentation.
  • An API key is both your ID and your bill; keep it like a password, or even more carefully.
  • Don't put a key in a chat, in the frontend or on GitHub; if it leaks, revoke it right away.

Test yourself

3 quick questions. Pick an answer and see the right one instantly.

1In the waiter analogy, what does the API's documentation correspond to?

Like a menu, the documentation explains what you can ask for and how to ask.

2AI tells you, “Paste your API key here and I'll write the code.” What's the right thing to do?

A key never goes into a chat, the frontend or a public repository; it lives in a secret file like .env.

3You suspect your API key has leaked. What should you do first?

A leaked key may be in other people's hands. It must be deleted and a new one created; just removing it from where it was shared isn't enough.
