Files, folders, extensions and paths

What do file, folder, extension and path mean? Learn the concepts you'll meet most when building projects with AI, using an address analogy.

Lesson 1/66 min readUpdated: November 2026
Contents3
  1. Files and folders
  2. Extensions: a file's ID label
  3. Paths: a file's full address

When AI tells you “open the src/index.html file” or “add this to the .env file,” you need to know what to do. In this lesson you'll learn the basic layout of a computer: files, folders, extensions and paths. One analogy will make all of them click.

The filing cabinet analogy

Picture an office. A file is a single sheet of paper with writing on it. A folder is a drawer in the filing cabinet that holds sheets together; there can be more drawers inside the drawer. An extension is the label in the corner of the sheet: “invoice,” “photo,” “contract.” And a path is that sheet's full address: “2nd floor, blue cabinet, top drawer, red file.”

Files and folders

Everything on your computer is a file: a photo, a song, a Word document, the code of a web page. Folders keep those files organized. In software projects you usually create one main folder per project, and everything that belongs to the project lives inside it. When working with AI agents, this main folder is called the project folder.

Extensions: a file's ID label

The part after the dot at the end of a file name is the extension. In invoice.pdf, the extension is .pdf. The computer often decides which program to open a file with by looking at this label. These are the extensions you'll see most often in vibe coding:

ExtensionWhat kind of file?Everyday equivalent
.htmlThe skeleton of a web pageThe walls of a house
.cssHow a web page looksPaint and decor
.jsJavaScript code, the page's behaviorElectrical wiring
.pyPython codeA machine's operating instructions
.jsonOrganized dataLabeled storage boxes
.csvTable data, as plain textA plain version of a spreadsheet
.mdMarkdown, a formatted noteA note with headings and bullet points
.envSecret settings and keysAn envelope in the safe

Make extensions visible

  1. Windows 11: Open File Explorer, go to View > Show in the top menu and check File name extensions.
  2. Windows 10: In File Explorer, switch to the View tab and check the File name extensions box.
  3. Mac: In Finder, choose Finder > Settings from the top menu, switch to the Advanced tab and check Show all filename extensions.

Paths: a file's full address

The full address of a file on your computer is called its path. Folder names are written in order with a separator between them. On Windows the separator is a backslash (\); on Mac and Linux it's a forward slash (/). The address of the same file on the two systems might look like this:

These full addresses are called absolute paths; they're like an address that starts with the country and goes all the way to the apartment number. There are also relative paths: like saying “two doors down from where you are.” Writing images/logo.png inside a project means “the logo inside the images folder in the folder you're in.” And ../ means “go up one folder.” Projects usually use relative paths, because a relative path keeps working when the folder is moved to another computer.

Golden rules for project files

  • Don't use spaces or accented/special characters in file and folder names: write profit-calc.html instead of Profit Calc (final).html.
  • Separate words with hyphens and use lowercase. Many servers on the internet treat uppercase and lowercase as different; Logo.png and logo.png are two separate files there.
  • On Mac and Linux, files whose names start with a dot (.env, .gitignore) are hidden; on Mac, press Cmd + Shift + . in Finder to show them. On Windows these files usually show up normally; to see a hidden item, check View > Show > Hidden items in File Explorer.

Set up your own workshop

  1. Create a folder named vibe-projects on your desktop.
  2. Inside it, create a second folder named first-project.
  3. Move the profit-calculator.html file you saved in the day-one lesson here. If you don't have the file, copy the code from the chat and save it into this folder using plan B from that lesson.
  4. Copy the file's path. On Windows, right-click the file and choose Copy as path. On Mac, hold down the Option key while right-clicking the file; an option to copy the path appears in the menu.
  5. Paste the path you copied somewhere and read which folders it goes through.

Key takeaways

  • The extension tells you a file's type; the path tells you its full address on the computer.
  • Windows paths are separated with \, Mac and Linux paths with /.
  • Don't use spaces or special characters in project files; prefer lowercase and hyphens.

Names with lowercase letters, hyphens and no spaces or special characters work without trouble on every system and server.
