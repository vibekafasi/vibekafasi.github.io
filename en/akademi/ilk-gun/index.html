Day one: sign up and build your first mini app without installing anything

Without installing anything, using only your browser, build your first mini app in Claude or ChatGPT: a profit calculator, step by step.

Lesson 5/58 min readUpdated: November 2026

Today you'll build your first app. No programs to install, no terminal, no server. All you need is a browser and a free account. By the end you'll have a small tool that really works and calculates your profit from the selling price.

The test kitchen analogy

Before opening a restaurant, you try the dish at home. The chat screen in Claude and ChatGPT is your test kitchen: you have the code written, run it on the same screen and taste it. If you don't like it, you change the recipe. Opening the restaurant, meaning putting it on the internet, is a job for later modules.

1. Create your account

  1. Go to claude.ai for Claude or chatgpt.com for ChatGPT. Both have a free plan; you only need to pick one to get started. Both services are available only in supported countries; check the official lists linked in the sources below.
  2. Sign up with your email address or Google account. Confirm the verification email you receive.
  3. Make sure the email your account is tied to has a strong password. Work you put effort into will live in this account later.

2. Path A: an artifact with Claude

Claude shows larger, stand-alone outputs in a separate panel that opens next to the chat. This is called an artifact. A small web app runs there as an artifact too, and you can click its buttons to try it. Artifacts work on the free plan as well.

  1. First check the setting: click your name in the bottom left, and in Settings open the Capabilities tab. The path is Settings → Capabilities → Create and edit files (old name: Code execution and file creation). If it is off, turn it on.
  2. Open a new chat, paste the ready-made prompt below and send it.
  3. Once Claude writes the code, the app opens next to the chat. If it doesn't, just type “Show this as an artifact.”
  4. If you see an error, click the Try fixing with Claude button that appears in the panel; the error details are copied into a new message and Claude looks into the problem.
  5. Everything you make is saved in the Artifacts tab in the left menu. New artifacts start out private to you; nobody can see them unless you share them.

3. Path B: a preview with ChatGPT

  1. Send the same prompt to ChatGPT. Make sure the prompt includes the phrase “a single HTML file.”
  2. Look for the Preview button above the code block in the answer and click it. The app runs inside the chat; to go back to the code, click Code.
  3. If you don't see a Preview button, ChatGPT isn't offering a preview for that code block; this feature can vary by plan, device and model. In that case, use plan B below.
Tip

Plan B needs no setup either: copy the code, paste it into Notepad (on Mac, use TextEdit in plain-text mode) and save it as profit-calculator.html. When saving in Notepad, set the file type to “All files.” Then double-click the file; it opens in your browser and works.

4. Your first app: a profit calculator

5. Test it: check the math by hand

Don't assume you're done just because the app opened. Try it with an example where you know the answer: enter purchase 10, selling 20, fee 15%, shipping 3. The fee is 15% of 20, which is $3. Net profit should be 20 − 10 − 3 − 3 = $4, and the profit margin 4 / 20 = 20%. If the app shows that, congratulations, you've passed your first test too. Then leave a field empty and type letters; see whether the warning appears.

6. Ask for a small change

Did you notice? You said clearly what you wanted added, and you also said what must not be touched. That's one of the most valuable habits in vibe coding. After the change, try the same test values again; the old feature shouldn't have broken.

Watch out

Never type real customer information, passwords, card numbers or an API key into the chat or your test apps. Always use made-up data for experiments.

If you get stuck

  • If the app doesn't show up at all: say “Rewrite this as a single-file HTML app that can be previewed.”
  • If the math is wrong: write exactly, “With purchase 10, selling 20, fee 15 and shipping 3, I should get $4, but I get X.”
  • If you don't like the design: say what you don't like, for example “The text is too small; make the button bigger.”

Key takeaways

  • With Claude's artifacts or ChatGPT's Preview feature, you can build an app with no setup.
  • It isn't done just because it opened; test it by hand with an example where you know the answer.
  • When asking for a change, say both what to add and what not to touch.

Test yourself

3 quick questions. Pick an answer and see the right one instantly.

1In Claude, what do you call the panel that opens next to the chat where a small app can run?

Claude shows large, stand-alone outputs as artifacts next to the chat; small apps run there.

2If the purchase price is $10, the selling price $20, the fee 15% and shipping $3, what should the net profit be?

The fee is 15% of 20, which is $3. 20 − 10 − 3 − 3 = $4.

3If there's no Preview button on the code block in ChatGPT, what can you do without installing anything?

A single-file HTML app runs in the browser when you save it with the .html extension and double-click it.

Great! Your progress is saved in this browser.
