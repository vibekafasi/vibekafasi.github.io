Data formats: JSON and CSV

What are JSON and CSV, and when do you use each? Learn their rules, common mistakes and the garbled-character problem, with examples.

Lesson 6/66 min readUpdated: November 2026
Contents3
  1. JSON: labeled boxes
  2. CSV: the plain version of a table
  3. Two common CSV problems

Whether programs are sending each other information or storing it in a file, they use shared formats everyone understands. The two most common are JSON and CSV. A response from an API is usually JSON, while an order report you download from a marketplace is usually CSV or Excel.

JSON: labeled boxes

Labeled storage boxes

When you move, you write labels on the boxes: “Kitchen: plates,” “Bedroom: winter clothes.” JSON works the same way. Every piece of information has a label (key) and contents (value). You can put boxes inside other boxes too; JSON can hold nested information.

JSON's rules

  • A JSON like the one in the example starts and ends with curly braces { }. This is an object, a labeled box.
  • Labels and text go in double quotes: "name". Single quotes aren't accepted.
  • A colon : goes between a label and its value, and a comma , between two items.
  • Numbers are written without quotes and use a dot for decimals: 19.90.
  • A list is written with square brackets: ["S", "M", "L"].
  • Use true and false for yes/no and null for an empty value; these go without quotes too.
  • There's no comma after the last item. You also can't write comment lines in JSON.

CSV: the plain version of a table

CSV stands for “comma-separated values.” It's the plain-text, no-frills version of a spreadsheet. The first row usually holds the column headers, and each row after that is a record. Values are split into columns by the commas between them.

Look at the last row: because the product name contains a comma, the name is wrapped in double quotes. That way the program doesn't mistake that comma for a column separator.

Two common CSV problems

  • Semicolons: In regions where the comma is the decimal separator (much of Europe, for example), Excel often separates columns with a semicolon ; when saving CSV. If a program can't read the file, just tell the AI “The separator is a semicolon.”
  • Garbled characters: If you see strange characters like “CafÃ©” instead of “Café,” the file's character encoding doesn't match. Choosing CSV UTF-8 under Save As in Excel solves this problem in most cases.
Watch out

Think twice before uploading a CSV file with a real customer list to AI. Work on a copy with the personal information like names, phone numbers and addresses removed, or prepare a sample file with the same structure and made-up data.

Try it yourself

  1. Copy the JSON example above and paste it into Claude or ChatGPT.
  2. Make a mistake in it on purpose: for example, delete one of the quotes around the value "Chicago".
  3. Send the prompt below and see whether the AI finds the mistake.
  4. Then ask it to convert the same data to CSV and compare the two formats side by side.
Tip

When describing an Excel spreadsheet to AI, pasting the first few rows as CSV usually gives more accurate results than sending a screenshot.

Key takeaways

  • JSON is labeled, nested boxes; APIs usually speak JSON.
  • CSV is the plain-text version of a table; it opens easily in Excel.
  • If characters come out garbled, check for UTF-8; if columns get mixed up, check the separator.
