What are code and programming languages? (HTML, JavaScript, Python)

What is code, and what is a programming language for? Meet HTML, CSS, JavaScript and Python through a house analogy and run your first code in the browser.

Lesson 2/66 min readUpdated: November 2026

If AI is going to write the code, why do you need to know what code is? Because using the right words when you tell AI what you want, understanding the result and knowing where to look when something goes wrong saves you time and money. You won't learn to write code; you'll learn to recognize it.

Code: a recipe written for the computer

The cook who follows every word

Think of a recipe: “Chop the onion, heat the oil, fry the onion.” Now imagine handing it to a cook who never interprets anything and follows every word literally. If you write “heat the oil” without saying how much, the oil might burn. The computer is that cook. Code is the recipe written for it, and a programming language is the language the recipe is written in.

Just like human languages, programming languages have grammar rules. If a comma is missing, the computer doesn't understand the recipe and throws an error. The good news: AI knows these rules very well. Your job is to explain clearly what the recipe should do.

A web page is built with three languages

The house analogy

Picture a house. HTML is the walls and rooms: here's the kitchen, here's the door. CSS is the paint and decor: the wall is blue, the door is wooden. JavaScript is the electrical wiring: press the switch and the light turns on. There's no paint without walls, and the wiring runs through the walls; all three work together.

  • HTML: Says what's on the page: heading, paragraph, image, button. It's actually not a full programming language but a markup language; it marks up content with tags.
  • CSS: Says how the page looks: color, font, spacing, layout on phones.
  • JavaScript: Gives the page behavior: calculating when a button is clicked, opening a menu, fetching data. It runs inside the browser; thanks to Node.js it can run on servers too.

Python: the worker behind the scenes

Python is a programming language beginners love because it's easy to read. It usually runs not inside a web page but on your computer or a server. It's used a lot for processing spreadsheets, organizing files, preparing reports, automations and AI projects.

Run your first code without installing anything

  1. Open any page in Chrome, Edge or Firefox.
  2. Press F12 on your keyboard. In the developer tools that open, switch to the Console tab. On a Mac in Chrome, Cmd + Option + J opens the same place.
  3. On the bottom line, type 2 + 2 and press Enter. The answer comes back as 4. You just ran JavaScript.
  4. Now type alert("Hello from Vibe Kafası") and press Enter. An alert box appears on the screen.
  5. When you're done, press F12 again to close the panel. When you reload the page, everything goes back to how it was.
Watch out

Small experiments you type into the console yourself are harmless. But never run code a stranger tells you to “paste into the console”; this trick is used to steal accounts. That's why your browser may warn you when you paste.

Tip

Naming the language in your prompt makes things easier: “a single HTML file,” “a small Python script,” and so on. If you're not sure, ask: “Which is the simplest language to build this in? Suggest one.”

Key takeaways

  • Code is a recipe the computer follows to the letter.
  • A web page: HTML for structure, CSS for looks, JavaScript for behavior.
  • Python usually runs on a computer or server; it's used a lot for data and automation.

Test yourself

3 quick questions. Pick an answer and see the right one instantly.

1On a web page, which one sets a button's color and size?

CSS is responsible for how the page looks: color, size, font and layout.

2Which language usually makes a calculation happen when you click a button?

JavaScript gives the page behavior; it reacts to clicks and does calculations.

3Someone tells you, “Paste this code into your browser console and you'll win a prize.” What should you do?

Running code from strangers in the console can lead to your account being taken over.
