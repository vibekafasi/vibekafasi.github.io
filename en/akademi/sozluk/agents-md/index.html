What is AGENTS.md?

Also known as: AGENTS.md

A rules file in a shared format read by Codex and many other coding agents.

AGENTS.md in the project root holds project rules; ~/.codex/AGENTS.md holds your general rules for all projects. If you put a separate AGENTS.md in a subfolder, it takes precedence over the more general rules while working in that folder. Claude Code doesn't read this file on its own; you can import it by writing @AGENTS.md inside CLAUDE.md.
