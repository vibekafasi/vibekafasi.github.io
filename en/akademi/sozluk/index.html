.env .env file

A file in the project folder where secret settings like API keys are kept in NAME=value form.

It's like keeping your credit card in a safe instead of taping it to the shop window. The code reads the key from this file when it runs; the file itself doesn't go to GitHub thanks to .gitignore. Its name starts with a dot and it has no extension.

Example: ANTHROPIC_API_KEY=your-own-key-here

.gitignore .gitignore

A list that tells Git which files and folders it should never track.

It's like a “never ship this box” list you give the shipping clerk. Secret or very large things like .env, node_modules and .venv go in it. It must be set up before the first commit; once a file has been committed, adding it to the list doesn't remove it from history.

Example: The lines .env and .env.* keep secret files out, while !.env.example makes sure the example file isn't ignored.

3-2-1 rule 3-2-1 backup rule

A backup rule: keep 3 copies of your data, on 2 different types of storage, with 1 kept off-site.

It's like keeping one copy of your house key in your pocket, one in a drawer and one with a relative you trust. For example, the main files are on your computer, one backup on an external drive and one in the cloud: three copies, two kinds of storage, one outside the house. Even if the computer is stolen or the house burns down, the cloud copy survives.

API Application Programming Interface

A door with clear rules through which two programs ask each other for information or services.

It's like a waiter in a restaurant: you don't go into the kitchen, you order from the menu, and the waiter brings the plate. Adding AI to your app, showing exchange rates or pulling orders from a marketplace are all done through APIs.

Example: A request GET /api/tracking?no=US123456 goes to a shipping-tracking API and a JSON response like {"status": "Out for delivery"} comes back.

Example: A Claude API key is created in the Claude Console; an OpenAI key on OpenAI's developer platform.

S

Salt salt

A random value unique to each user, added to a password before it's hashed.

It's like adding a different spice to the ground meat for each user: even if two people pick the same password, their records look different. That makes precomputed hash tables useless, and an attacker has to try each password separately. A salt isn't secret; it's stored next to the hash, and modern password-hashing methods add it automatically.

Undo (Git) restore / revert

Canceling a change or commit in Git and returning the project to its earlier state.

git restore throws away unsaved changes in a file; git revert adds a new commit that does the opposite of an old one, and since history isn't deleted, it's the safest way. git reset --hard and git push --force, on the other hand, can do irreversible things; don't use them unless you're sure what you're doing.

Example: git revert a1b2c3d creates a new save point that undoes the change in that commit.
