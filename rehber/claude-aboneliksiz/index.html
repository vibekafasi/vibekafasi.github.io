Claude Code
aboneliksiz nasıl kurulur?

Claude masaüstü uygulamasını aylık 20 $ abonelik olmadan, OpenRouter anahtarınla kullan. 10 dakikada biter, teknik bilgi gerekmez.

💡 Dürüst not: Bu yol ücretsiz değil. Abonelik yok ama kullandığın kadar OpenRouter bakiyenden düşer. Az kullanana ucuz gelir, çok kullanana pahalıya gelebilir. Bir benzetme: aylık otopark kartı yerine saatlik ödemek gibi.

ADIM 1

OpenRouter anahtarı al

OpenRouter, birçok yapay zekâ modelini tek hesaptan kullandıran bir aracı. Claude bu hesap üzerinden çalışacak.

1

Hesap aç

openrouter.ai adresine gir ve Google ya da e-posta ile kaydol.

2

Bakiye yükle

Credits sayfasından küçük bir tutarla başla (örneğin 5 $). Bakiye yoksa uygulamada model listesi boş görünür.

3

Anahtar oluştur

Keys sayfasında Create Key'e bas. İstersen anahtara bir harcama sınırı koy. Çıkan sk-or-v1-… ile başlayan yazıyı kopyala ve bir yere not et.

🔒 Anahtarı kimseyle paylaşma. Ekran görüntüsünde, videoda ya da yorumda görünmesin. Görünürse Keys sayfasından silip yenisini oluştur.
ADIM 2

Claude'u indir ve kur

1

İndir

claude.com/download adresinden bilgisayarına uygun sürümü indir (Windows ya da macOS).

2

Kur ve aç

Kurulum bitince uygulamayı aç. Claude hesabına giriş yapma, gerek yok.

ADIM 3

Geliştirici modunu aç

Uygulamanın üst menüsünden (Windows'ta sol üstteki ☰ / ··· menüsü):

Yardım→Sorun giderme→Geliştirici modunu etkinleştir…

Çıkan soruyu onayla. Menüde yeni bir Geliştirici menüsü belirir.

🌐 Uygulaman İngilizceyse aynı yol: Help → Troubleshooting → Enable Developer Mode.
ADIM 4

Gateway bağlantısını yap

Geliştirici→Üçüncü taraf çıkarımı yapılandır…

Açılan pencerede bağlantı türünü Gateway seç ve alanları doldur. Bu pencere uygulamada şimdilik İngilizce görünebilir; alan adları aşağıda iki dilde:

INFERENCE PROVIDER · ÇIKARIM SAĞLAYICISIGateway (Anthropic-compatible)
GATEWAY BASE URL · GATEWAY ADRESİ
https://openrouter.ai/api
GATEWAY API KEY · GATEWAY API ANAHTARIAdım 1'de kopyaladığın sk-or-v1-… anahtarı
GATEWAY AUTH SCHEME · KİMLİK DOĞRULAMAbearer
CREDENTIAL KIND · KİMLİK TÜRÜStatic API key (sabit API anahtarı)

Client ID, Issuer URL gibi isteğe bağlı alanları boş bırak. Sonra Apply Changes (Değişiklikleri uygula) düğmesine bas. Eski sürümlerde bu düğmenin adı Apply locally.

⚠️ Adresin sonuna /v1 ekleme. Tam olarak https://openrouter.ai/api olmalı.
ADIM 5

Yeniden başlat ve kullan

1

Tamamen kapat

Pencereyi kapatmak yetmez: uygulamadan tamamen çık (Windows'ta saatin yanındaki simgeden Çık, Mac'te Cmd+Q), sonra tekrar aç.

2

Gateway ile devam et

Açılış ekranında Continue with Gateway seçeneğine bas (bazı sürümlerde Local configuration yazar).

3

Code sekmesine geç

Model seçicide OpenRouter üzerinden kullanabildiğin modeller listelenir. Code sekmesini aç: Claude Code hazır. 🎉

ÖNEMLİ

Harcamayı kontrol et

Her mesaj OpenRouter bakiyenden düşer; düşünme (reasoning) adımları da ücrete dahil. Sürpriz yaşamamak için:

1

Anahtara sınır koy

Keys sayfasında anahtarın harcama sınırını belirle. Sınır dolunca durur, fazlası çekilmez.

2

Harcamaya bak

Activity sayfasında hangi işin ne kadar tuttuğunu görürsün.

3

En uyumlu sağlayıcı

OpenRouter'a göre tam uyum yalnız Anthropic'in kendi sağlayıcısında garanti. Sorun yaşarsan OpenRouter yönlendirme ayarlarında Anthropic'i ilk sıraya koy.

SORUN ÇÖZME

Çalışmıyorsa ne yaparım?

Geliştirici menüsü çıkmadı
Yardım → Sorun giderme → Geliştirici modunu etkinleştir… adımını tekrar yap ve çıkan soruyu onayla. Gerekirse uygulamayı kapatıp aç.
Bağlantı hatası veriyor
Adresin tam olarak https://openrouter.ai/api olduğunu, anahtarın doğru kopyalandığını ve kimlik doğrulamanın bearer olduğunu kontrol et.
Model listesi boş
OpenRouter hesabında bakiye olduğundan emin ol (Credits sayfası).
“Continue with Gateway” görünmüyor
Apply Changes'e bastığından emin ol ve uygulamadan tamamen çıkıp yeniden aç.
Claude Code bir siteye erişemiyor
Araç trafiği varsayılan olarak kısıtlı. Geliştirici → Üçüncü taraf çıkarımı yapılandır… → Workspace restrictions sekmesinde Allowed egress hosts listesine o siteyi ekle.
