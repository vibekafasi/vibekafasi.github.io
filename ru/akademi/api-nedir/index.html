Что такое API и зачем нужен API-ключ?

API — дверь, через которую программы просят друг у друга услуги. На примере официанта разбираем API, API-ключ и правила, как хранить ключ в безопасности.

Урок 5/67 мин чтенияОбновлено: ноябрь 2026

Вводишь на сайте трек-номер — и видишь, где сейчас твоя посылка. Этот сайт не залезает в компьютер службы доставки: он вежливо просит у нее информацию. Дверь, через которую проходит такая просьба, называется API. Когда захочешь добавить в свое приложение ИИ, показать курс валют или выгрузить заказы с маркетплейса, ты всегда будешь пользоваться этой дверью.

Как с официантом

В ресторане ты не идешь на кухню готовить сам. Ты говоришь официанту, что выбрал в меню, он относит заказ на кухню и приносит тебе тарелку. API — это официант. Меню — документация API: в ней написано, что можно заказать и как. Заказ — твой запрос, а тарелка — пришедший ответ. Знать, что происходит на кухне, не нужно: достаточно соблюдать правила из меню.

Что можно делать через API?

  • Добавить в приложение ИИ: твой сайт отправляет вопрос моделям Claude или GPT и получает ответ.
  • Показывать на своей странице готовые данные: погоду, курсы валют, карты.
  • Выгружать заказы и остатки с маркетплейса, на котором ты продаешь; у большинства крупных маркетплейсов есть API для продавцов.
  • Автоматически отправлять сообщения в Telegram, письма на почту, принимать оплату.

API-ключ: и паспорт, и банковская карта

Многим API нужно знать, кто именно отправляет запрос. Для этого тебе выдают длинный сложный пароль — API-ключ. Твое приложение показывает этот ключ при каждом запросе. А сервис записывает расходы и выставляет счет владельцу ключа, то есть тебе.

Как карта-ключ в отеле

API-ключ похож на карту в отеле, которая открывает дверь номера и заодно позволяет записывать счета из ресторана на твой номер. Потеряешь карту — и нашедший сможет и в номер войти, и пообедать за твой счет. Поэтому API-ключ нужно хранить так же бережно, как пароль, а то и бережнее.

Например, ключ для API Claude создается на странице API-ключей в Claude Console. Ключи OpenAI создаются на платформе OpenAI для разработчиков. Внимание: подписка на claude.ai или ChatGPT и использование API — разные продукты. Использование API обычно оплачивается отдельно и по факту расхода. Актуальные цены всегда проверяй на официальной странице с тарифами.

5 золотых правил для API-ключа

  • Не вставляй его в чат. Когда просишь ИИ написать код, сообщай не сам ключ, а то, что «ключ лежит в файле .env».
  • Не клади его во фронтенд. Ключ, вписанный в код, который работает в браузере, может увидеть любой.
  • Не загружай его на GitHub. Файл .env должен быть в списке .gitignore. Мы сделаем это шаг за шагом в модуле о безопасности (модуль 6).
  • Поставь лимит расходов. Следи за расходами в панели управления и, если сервис позволяет, установи лимит расходов.
  • Утек — сразу отзывай. Если подозреваешь, что ключ кто-то видел, удали его в панели и создай новый.
Внимание

Ключи, загруженные в публичный репозиторий на GitHub, автоматические программы-сканеры могут найти за считаные минуты. Anthropic участвует в программе GitHub по сканированию секретов и автоматически отключает API-ключи Claude, найденные в публичных репозиториях. Но не рассчитывай на это: единственное настоящее решение — вообще не загружать ключ.

Попробуй API без ключа прямо в браузере

  1. Введи в адресной строке браузера https://api.github.com/users/octocat и нажми Enter. Octocat — аккаунт талисмана GitHub.
  2. На экране появится текст, полный фигурных скобок; Firefox может показать его и в аккуратном виде. Это ответ API GitHub в формате JSON.
  3. Найди в нем метки вроде "login", "name", "public_repos". Рядом с каждой меткой стоит значение.
  4. Замени octocat в конце адреса на другое имя пользователя GitHub и попробуй снова. Ты только что сделал официанту другой заказ.

Главное

  • API — официант, через которого программы просят друг у друга услуги; его меню — документация.
  • API-ключ — и твой паспорт, и твоя банковская карта; храни его как пароль, а то и бережнее.
  • Не клади ключ в чат, во фронтенд и на GitHub; если он утек, сразу отзывай.

Проверь себя

3 коротких вопроса. Выбери ответ — сразу увидишь правильный.

1Чему в аналогии с официантом соответствует документация API?

Документация, как и меню, рассказывает, что можно заказать и как это сделать.

2ИИ пишет тебе: «Вставь сюда свой API-ключ, а код я напишу сам». Как правильнее всего поступить?

Ключ никогда не кладут в чат, во фронтенд или в публичный репозиторий: он хранится в секретном файле вроде .env.

3Ты подозреваешь, что твой API-ключ утек. Что сделать в первую очередь?

Утекший ключ может быть уже в чужих руках. Его нужно удалить и создать новый; просто убрать его оттуда, где он засветился, недостаточно.
