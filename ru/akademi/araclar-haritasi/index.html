Академия / Модуль 1: Старт

Claude, ChatGPT, Codex, Cursor: что для чего?

Чем чат-ассистент отличается от агента для программирования и редактора кода с ИИ. Учимся применять Claude, Claude Code, ChatGPT, Codex и Cursor по делу.

Урок 3/56 мин чтенияОбновлено: ноябрь 2026

В названиях ИИ-инструментов легко запутаться: Claude, Claude Code, ChatGPT, Codex, Cursor… На самом деле все их можно разложить по трем коробкам. Разберешься с коробками — и сразу поймешь, какой инструмент открывать под какую задачу.

Кухонная аналогия

Чат-ассистент — как друг-повар, который диктует рецепт по телефону: ты спрашиваешь, он объясняет и пишет рецепт, но мешаешь в кастрюле ты сам. Агент для программирования — повар, который пришел к тебе на кухню: открывает шкафы, находит продукты и готовит сам, а ты смотришь и даешь добро. Редактор кода с ИИ — современная кухня со встроенными умными помощниками.

1. Чат-ассистенты: Claude и ChatGPT

Claude — чат-ассистент от Anthropic, ChatGPT — от OpenAI. Оба работают в браузере и в мобильном приложении, у обоих есть бесплатный план. Они отлично подходят, чтобы развивать идеи, писать тексты, разбираться в ошибках и пробовать небольшие приложения. Оба умеют показывать написанные ими небольшие веб-страницы в рабочем виде прямо в чате. В Claude такие результаты называются артефактами (artifacts), а в ChatGPT предпросмотр открывается кнопкой Preview над блоком кода. Учти: эти сервисы официально работают только в поддерживаемых странах (например, в России они официально недоступны). Перед регистрацией проверь официальные списки стран: у Anthropic для Claude и у OpenAI для ChatGPT (ссылки — в источниках внизу урока).

2. Агенты для программирования: Claude Code и Codex

Агент для программирования, или кодинг-агент, — это ИИ, который получает доступ к папке проекта на твоем компьютере или в облаке и сам читает файлы, правит их и запускает команды. Чат-ассистент выдает тебе код, а агент сам вставляет его на место, запускает и тестирует.

  • Claude Code: агент для программирования от Anthropic. Работает в терминале, внутри редакторов VS Code и JetBrains, в приложении для компьютера и в браузере (claude.ai/code). Для работы нужен платный план Claude или аккаунт API.
  • Codex: агент для программирования от OpenAI. Работает в терминале (Codex CLI), как расширение редактора, в приложении ChatGPT для компьютера и в облаке (Codex Cloud). Входишь через аккаунт ChatGPT. Доступен в планах ChatGPT, включая бесплатный; сколько им можно пользоваться на каждом плане, написано на официальной странице с ценами.

3. Редактор кода с ИИ: Cursor

Редактор кода — это программа, в которой открывают и правят файлы с кодом: что Word для текста, то редактор для кода. Cursor — редактор кода со встроенным ИИ-агентом. Файлы у тебя перед глазами, и ты видишь, что именно меняет агент. Внутри можно выбирать модели разных компаний, например Claude и GPT. Бесплатный план тоже есть.

Оба агента из таблицы умеют планировать, писать код, запускать тесты и искать ошибки. Разница между ними скорее в интерфейсе, экосистеме и личных привычках. Составить точный рейтинг, кто «умнее», трудно: модели часто обновляются, а результат зависит от задачи.

С чего начать?

  1. Первая неделя: пользуйся только чат-ассистентом (Claude или ChatGPT). Ничего устанавливать не нужно, никакого риска.
  2. Первый настоящий проект: когда начнешь работать с файлами, переходи на агента для программирования (Claude Code или Codex).
  3. Когда захочешь видеть код: добавь редактор кода. Можно поставить расширение с агентом в VS Code или попробовать Cursor.
  4. Второе мнение: в важной задаче полезно давать план, написанный одним инструментом, на проверку другому.
Внимание

Агенты для программирования могут менять твои файлы и запускать команды. Прежде чем что-то одобрить, прочитай, что агент собирается сделать. Первые эксперименты проводи в отдельной папке, где нет важных файлов.

Главное

  • Чат-ассистент выдает код, а агент для программирования сам вставляет его на место и запускает.
  • Claude Code и Codex — агенты, Cursor — редактор кода с ИИ.
  • Для начала хватит одного инструмента; главное — хороший запрос и проверка.

Проверь себя

3 коротких вопроса. Выбери ответ — сразу увидишь правильный.

1В чем главное отличие чат-ассистента от агента для программирования?

Чат-ассистент выдает код тебе, а агент сам меняет файлы, запускает команды и тестирует.

2Что из перечисленного — редактор кода?

Cursor — редактор кода со встроенным ИИ-агентом. Claude Code и Codex — агенты для программирования, а ChatGPT — чат-ассистент.

3Ты хочешь попробовать вайб-кодинг, вообще ничего не устанавливая. С чего лучше всего начать?

Чат-ассистенты работают в браузере, их можно попробовать на бесплатном плане; для первого шага это самый безопасный путь.
