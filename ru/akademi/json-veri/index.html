Форматы данных: JSON и CSV

Что такое JSON и CSV и когда какой нужен? На примерах разбираем правила, частые ошибки и проблему «кракозябр» вместо русских букв.

Урок 6/66 мин чтенияОбновлено: ноябрь 2026

И когда программы передают друг другу информацию, и когда хранят ее в файле, они используют общие форматы, понятные всем. Два самых распространенных — JSON и CSV. Ответ от API чаще всего приходит в JSON, а отчет о заказах, который ты скачиваешь с маркетплейса, обычно бывает в CSV или Excel.

JSON: подписанные коробки

Подписанные коробки для хранения

При переезде ты подписываешь коробки: «Кухня: тарелки», «Спальня: зимние вещи». JSON устроен так же. У каждого элемента данных есть метка (ключ) и содержимое (значение). В коробки можно класть другие коробки — и JSON тоже умеет хранить вложенные данные.

Правила JSON

  • JSON, как в примере, начинается и заканчивается фигурными скобками { }. Это объект, то есть подписанная коробка.
  • Метки и текст пишутся в двойных кавычках: "name". Одинарные кавычки не допускаются.
  • Между меткой и значением ставится двоеточие :, между элементами — запятая ,.
  • Числа пишутся без кавычек, а дробная часть отделяется точкой: 1299.90.
  • Список пишется в квадратных скобках: ["S", "M", "L"].
  • Для «да/нет» используются true и false, для пустого значения — null; они тоже пишутся без кавычек.
  • После последнего элемента запятая не ставится. Комментарии в JSON писать тоже нельзя.

CSV: таблица без украшений

CSV означает «значения, разделенные запятыми». Это таблица Excel без оформления, в виде простого текста. Первая строка обычно содержит заголовки столбцов, а каждая следующая строка — одна запись. Значения разбиваются на столбцы запятыми между ними.

Обрати внимание на последнюю строку: в названии товара есть запятая, поэтому название взято в двойные кавычки. Так программа не примет эту запятую за разделитель столбцов.

Две частые проблемы с CSV в русскоязычной среде

  • Точка с запятой: на компьютерах с русскими региональными настройками дробная часть отделяется запятой, поэтому Excel при сохранении CSV часто разделяет столбцы точкой с запятой ;. Если программа не может прочитать файл, просто скажи ИИ: «Разделитель — точка с запятой».
  • «Кракозябры» вместо букв: если вместо «Футболка» ты видишь что-то вроде Р¤СѓС‚Р±РѕР»РєР°, значит, не совпадает кодировка файла. Обычно помогает пересохранить файл в Excel через Сохранить как, выбрав формат CSV UTF-8.
Внимание

Дважды подумай, прежде чем загружать ИИ файл CSV с реальным списком клиентов. Удали персональные данные вроде имен, телефонов и адресов или подготовь файл-пример с той же структурой и выдуманными данными.

Попробуй сам

  1. Скопируй пример JSON выше и вставь его в Claude или ChatGPT.
  2. Специально сделай в нем ошибку: например, удали одну из кавычек у значения "Иваново".
  3. Отправь запрос ниже и посмотри, найдет ли ИИ ошибку.
  4. Потом попроси перевести те же данные в CSV и сравни два формата рядом.
Совет

Когда объясняешь ИИ таблицу Excel, вставить первые несколько строк в виде CSV обычно надежнее, чем отправлять скриншот.

Главное

  • JSON — подписанные вложенные коробки; API обычно «говорят» на JSON.
  • CSV — таблица в виде простого текста; она легко открывается в Excel.
  • Если буквы превратились в «кракозябры», проверь UTF-8; если столбцы перепутались — разделитель.

Проверь себя

3 коротких вопроса. Выбери ответ — сразу увидишь правильный.

1Какой из вариантов — корректный JSON?

В JSON метки и текст должны быть в двойных кавычках, а после последнего элемента запятая не ставится.

2Ты хочешь открыть в Excel и изучить отчет о заказах, скачанный с маркетплейса. Какой формат подходит лучше всего?

CSV — простая таблица, и Excel открывает ее напрямую.

3Ты открываешь CSV-файл и вместо «Футболка» видишь бессмысленные символы. Какая причина вероятнее всего?

«Кракозябры» вместо русских букв обычно означают проблему с кодировкой; сохранение в формате CSV UTF-8 чаще всего ее решает.
