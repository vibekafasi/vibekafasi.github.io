Что такое код и язык программирования? (HTML, JavaScript, Python)

Что такое код и зачем нужен язык программирования? Знакомимся с HTML, CSS, JavaScript и Python на примере дома и запускаем первый код в браузере.

Если код будет писать ИИ, зачем тебе знать, что такое код? Затем, что так ты сможешь точнее формулировать запросы, понимать результат и знать, куда смотреть, когда что-то пошло не так. Это экономит время и деньги. Учиться писать код ты не будешь — ты научишься его узнавать.

Код: рецепт, написанный для компьютера

Повар, который все понимает буквально

Представь рецепт: «Нарежь лук, разогрей масло, обжарь лук». А теперь представь, что ты отдал его повару, который ничего не додумывает и выполняет каждое слово буквально. Напишешь «разогрей масло», но не скажешь, насколько, — масло может сгореть. Компьютер и есть такой повар. Код — рецепт для него, а язык программирования — язык, на котором этот рецепт написан.

Как и у человеческих языков, у языков программирования есть грамматика. Пропустишь одну запятую — компьютер не поймет рецепт и выдаст ошибку. Хорошая новость: ИИ отлично знает эти правила. Твоя задача — четко объяснить, что рецепт должен делать.

Веб-страница делается на трех языках

Как дом

Представь дом. HTML — это стены и комнаты: здесь кухня, здесь дверь. CSS — краска и отделка: стены синие, дверь деревянная. А JavaScript — электропроводка: нажал выключатель — загорелся свет. Без стен красить нечего, а проводка проходит внутри стен: все три работают вместе.

  • HTML: говорит, что есть на странице: заголовок, абзац, картинка, кнопка. Строго говоря, это не язык программирования, а язык разметки: он помечает содержимое тегами.
  • CSS: говорит, как страница выглядит: цвета, шрифты, отступы, расположение на телефоне.
  • JavaScript: добавляет странице поведение: посчитать что-то по нажатию кнопки, открыть меню, загрузить данные. Работает внутри браузера, а благодаря Node.js — и на серверах.

Python: работник, который трудится за кулисами

Python — язык программирования, который очень любят новички, потому что его легко читать. Обычно он работает не внутри веб-страницы, а на твоем компьютере или на сервере. Его часто используют, чтобы обрабатывать таблицы, наводить порядок в файлах, готовить отчеты, делать автоматизации и проекты с ИИ.

Запусти первый код без всякой установки

  1. Открой любую страницу в Chrome, Edge или Firefox.
  2. Нажми на клавиатуре F12. В открывшихся инструментах разработчика перейди на вкладку Console («Консоль»). На Mac в Chrome то же самое открывает сочетание Cmd + Option + J.
  3. В самой нижней строке напиши 2 + 2 и нажми Enter. Появится ответ: 4. Ты только что запустил JavaScript.
  4. Теперь напиши alert("Привет, Vibe Kafası") и нажми Enter. На экране появится окошко с сообщением.
  5. Когда закончишь, снова нажми F12, чтобы закрыть панель. После обновления страницы все вернется как было.
Внимание

Маленькие эксперименты, которые ты сам вводишь в консоль, безвредны. Но никогда не запускай код, который незнакомец просит «вставить в консоль»: так воруют аккаунты. Поэтому браузер может предупредить тебя при вставке.

Совет

Если в запросе указать язык, дело пойдет проще: «один HTML-файл», «небольшой скрипт на Python» и т. п. Не уверен — спроси: «На каком языке это проще всего сделать? Подскажи».

Главное

  • Код — рецепт, который компьютер выполняет буквально.
  • Веб-страница: HTML — структура, CSS — внешний вид, JavaScript — поведение.
  • Python обычно работает на компьютере или сервере и часто используется для данных и автоматизации.

Проверь себя

3 коротких вопроса. Выбери ответ — сразу увидишь правильный.

1Что на веб-странице задает цвет и размер кнопки?

CSS отвечает за внешний вид страницы: цвет, размер, шрифт и расположение.

2На каком языке обычно делают так, чтобы по нажатию кнопки выполнялся расчет?

JavaScript добавляет странице поведение: реагирует на нажатия и выполняет расчеты.

3Тебе говорят: «Вставь этот код в консоль браузера и получишь подарок». Что делать?

Запуск чужого кода в консоли может привести к тому, что твой аккаунт захватят.
