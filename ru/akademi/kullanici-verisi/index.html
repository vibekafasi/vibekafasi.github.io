Данные пользователей и пароли: базовые правила

Собирай минимум данных, не храни пароли открытым текстом, выбирай готовые системы входа. По законам вроде 152-ФЗ и GDPR советуйся с юристом.

Урок открыт для участников

Первые два модуля открыты для всех. Чтобы читать дальше, возьми бесплатный код в нашем Telegram-боте: подпишись на канал — и код придет сразу.

В этом уроке:
  • Правило 1: собирай меньше
  • Правило 2: пароли никогда не хранят открытым текстом
  • Правило 3: не пиши систему входа с нуля
  • Правило 4: знай законы, советуйся со специалистом
Получить код в Telegram

Код обновляется каждый месяц. Один раз введешь — браузер запомнит; в новом месяце возьми новый код у бота.
